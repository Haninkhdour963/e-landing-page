# e-landing-page
🍽️ E-Restaurant Landing Page
A clean and responsive landing page template for an online restaurant, built with HTML5 and CSS3, following semantic structure and best practices. This project showcases a modern and minimal design to present a restaurant’s brand, menu, and contact details in an engaging way.

📌 Features
Responsive Layout – Adapts to different screen sizes (desktop, tablet, mobile).

Semantic HTML – Proper use of <header>, <section>, <footer> for better SEO and accessibility.

Hero Section – Welcoming text and call-to-action button to guide visitors to the menu.

About Section – Short introduction about the restaurant.

Menu Section – Showcase of available dishes with customizable categories.

Contact Section – Email, phone, and address information.

Footer – Copyright and brand acknowledgment.

Normalize.css Integration – Ensures cross-browser consistency.

🎯 Customization
Edit styles.css to change colors, fonts, and layout.

Replace text and images in index.html with your restaurant’s content.

Add or remove menu categories as needed.
